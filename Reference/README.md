# Reference

Videos made by other people whose style you like: their cuts, captions, pacing, music, transitions.

- Drop the video files here (.mp4, .mov), or put links in links.txt.
- Optional: in notes.txt, write what you like about each one (for example: "the captions in clip-1, the fast cuts in clip-2").

Claude only studies these to understand the style. It does not copy their content.
