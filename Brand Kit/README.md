# Brand Kit

Your brand's files, so every video looks like it's from you.

- Logo (a transparent .png is best)
- Colors (hex codes, for example #1A73E8) in colors.txt
- Fonts (.ttf or .otf files)
- Intro or outro clip, if you have one
- Watermark, lower-third or end-card design
- Music or sound effects you're allowed to use (copyright-free)

Only put files here that you have the rights to use.
