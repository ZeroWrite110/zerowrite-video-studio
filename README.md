# Claude Video Editor (AI Video Editing Studio)

| Folder | What goes in it |
|---|---|
| Reference | Videos by other people whose style you like |
| Approved Videos | Your own finished edits that you're happy with |
| Editing Style | Notes on how your videos should be edited |
| Brand Kit | Logo, colors, fonts, intro/outro, music |
| Raw | One folder for each video you want edited |
| Export | Finished videos from Claude, ready to review and post |

How it works: put the footage in Raw/<video-name>/ and ask Claude to edit it.
Claude follows Editing Style and Brand Kit, and learns from Reference and Approved Videos.
The result lands in Export/<video-name>/.
