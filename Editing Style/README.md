# Editing Style

The rules for how your videos are edited, written in simple words. One file is enough, for example style.md.

What to write:
- Video size: 9:16 reel, 16:9 YouTube, or 1:1
- Length: for example 30-60 seconds
- Captions: font, size, color, position, word-by-word or full line
- Cuts: fast or slow, remove silences and "umm"s or not
- Music: type and volume
- Zooms, transitions, sound effects
- Things you never want

Claude reads this before every edit. If you're not sure, Claude can write a first draft of it from your Reference and Approved Videos.
