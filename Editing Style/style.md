# ZeroWrite editing style (DRAFT by Claude, change anything)

## Format
- Reels / Shorts / TikTok: 9:16, 20-40 seconds. YouTube: 16:9, 60-120 seconds.

## Look
- Brand Kit colours: dark ink background, cyan (#22D3EE) for the key word, green = allowed, amber = suspicious, red = blocked.
- Fonts: Inter for headlines, JetBrains Mono for file names, scores and labels.
- Show the product as clean UI cards (file cards, risk score, verdicts), like the website.
- ZeroWrite logo on the last scene; small logo in a corner is optional.

## Story
- First 3 seconds: a relatable moment (a download, an invoice, a USB stick). No fear-mongering.
- Then: problem -> what ZeroWrite does -> how (hold, read, decide) -> one next step.
- Use website wording where possible ("Stop threats before they run").
- No claims about other antivirus products until approved.

## Sound and text
- Calm, clear male or female voiceover. Short sentences.
- On-screen subtitle of the voiceover (most people watch muted).
- Music: soft, low; only copyright-free tracks from Brand Kit.

## Cuts
- Talking videos: cut pauses longer than 0.6 s, keep a little breathing room.
- One idea per scene, 3-6 seconds each.
